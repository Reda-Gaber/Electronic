# قاعدة بيانات متجر عبدالنبي للإلكترونيات

قاعدة بيانات **MySQL** مطابقة تمامًا لبيانات الفرونت الحالي (التصنيفات، المنتجات،
الطلبات، إعدادات المتجر، مناطق الشحن، حساب الأدمن). **مفيش جدول عملاء** لأن
الموقع يعمل بنظام Guest Checkout بالكامل (شراء بدون تسجيل دخول)، وتتبع الطلب
بيتم بالرقم المرجعي + رقم الهاتف بس.

## الملفات

| الملف | الوظيفة |
|---|---|
| `schema.sql` | إنشاء قاعدة البيانات وكل الجداول والعلاقات بينها |
| `seed.sql` | بيانات ابتدائية للاختبار (نفس بيانات الفرونت الوهمية حاليًا + حساب أدمن) |

## التشغيل محليًا (على جهازك، للتجربة قبل الرفع)

```bash
mysql --default-character-set=utf8mb4 -u root -p < schema.sql
mysql --default-character-set=utf8mb4 -u root -p < seed.sql
```

> ⚠️ **مهم:** لازم تحط `--default-character-set=utf8mb4` بالظبط زي فوق وقت
> الاستيراد من الـ Terminal، وإلا النصوص العربية هتتخزن بشكل غلط (Mojibake)
> حتى لو الجداول نفسها معمولة utf8mb4. لو بتستورد من MySQL Workbench بدل
> الـ Terminal، هي بتتعامل مع الترميز صح تلقائيًا فمش هتحتاج حاجة إضافية.

## الرفع على Hostinger

1. من hPanel: **Databases → MySQL Databases** → أنشئ قاعدة بيانات جديدة
   ومستخدم جديد وامنحه كل الصلاحيات عليها. سجّل اسم القاعدة/المستخدم/الباسورد.
2. افتح **phpMyAdmin** من نفس الصفحة → اختار القاعدة اللي أنشأتها.
3. تبويب **Import** → ارفع `schema.sql` أولاً → Go.
4. كرر نفس الخطوة وارفع `seed.sql` بعده.
5. بيانات الاتصال هتستخدمها بعدين في متغيرات البيئة (`.env`) بتاعة الباك اند:

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=اسم_المستخدم_من_hPanel
DB_PASSWORD=الباسورد_بتاعه
DB_NAME=اسم_القاعدة_من_hPanel
```

> ملحوظة: هوستنجر بيدعم MySQL بس (مش PostgreSQL أو MongoDB) على الخطط
> المشتركة والمُدارة، فالاختيار ده متوافق 100%. واستضافة Node.js متاحة على
> خطط Business وCloud تحديدًا.

## هيكل الجداول

```
categories ──< products ──< product_images
                   │    └─< product_specs
                   │
                   └──< order_items >── orders
shipping_zones                            (مستقل — بيُقرأ وقت حساب الشحن)
settings           (صف واحد بس)
admin_users         (مستقل)
```

## قرارات تصميم مهمة

- **productCount في التصنيفات مش متخزّن** — بيتحسب وقت الطلب بـ
  `COUNT(*) FROM products WHERE category_id = ?` عشان يفضل مطابق للواقع دايمًا.
- **order_items بتحفظ "لقطة" (snapshot)** من اسم/صورة/سعر المنتج وقت الشراء —
  عشان لو المنتج اتغيّر سعره أو اتحذف بعدين، تفاصيل الطلبات القديمة تفضل
  صحيحة زي ما كانت وقت الشراء بالظبط.
- **الرقم المرجعي للطلب (reference_number) هيتولّد من السيرفر** وقت إنشاء
  الطلب (مش من الفرونت زي دلوقتي) عشان نضمن إنه فريد دايمًا.
